# threads-persona-pages

Threads Persona 데스크톱 프로그램의 공개 안내 페이지 (GitHub Pages).

- `/callback/` - Meta(Threads) 앱에 등록하는 OAuth 리디렉션 주소. 프로그램이 연동 창에서 이 주소로 가는 순간을 가로채므로, 이 페이지는 일반 브라우저로 열었을 때만 보인다. 페이지는 주소의 값을 읽거나 보내지 않는다.

- `/deauthorize/` - Meta 앱의 "제거 콜백 URL". 정적 페이지라 Meta 의 알림(POST)은 처리하지 못한다. 연동이 해제되면 프로그램이 다음 API 호출의 인증 오류로 알아채 "재연동 필요"로 바꾼다.
- `/delete/` - Meta 앱의 "삭제 콜백 URL" 겸 데이터 삭제 안내. 데이터는 각 사용자 PC 에만 있어 중앙에서 지울 것이 없으므로, 사용자가 직접 지우는 방법을 안내한다.

코드·키는 이 저장소에 두지 않는다.
