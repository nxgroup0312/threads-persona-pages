데이터 삭제 안내

Threads Persona 는 데이터를 별도 서버에 보내 보관하지 않습니다. 연동한 계정 정보, 암호화한 Threads 접근 토큰, 글 초안·게시 기록은 프로그램을 설치한 PC 에만 저장됩니다.

데이터를 지우려면:

  1. 연동 해제 - Threads 계정 설정 → 웹사이트 권한에서 Threads Persona 를 삭제합니다.
  2. 계정 하나만 지우기 - 프로그램의 계정 화면에서 그 계정을 정지하고, 데이터 폴더의 기록이 필요 없으면 아래 3번으로 전부 지웁니다.
  3. 전부 지우기 - 프로그램을 끄고(트레이 아이콘 → 종료) 윈도우 설정 → 앱에서 "Threads Persona 관리"를 제거한 뒤, %APPDATA%\Threads Persona 관리 폴더를 삭제합니다.

글 생성에 쓰는 내용은 생성할 때 Anthropic(Claude) API 로 전송되며, 그 처리는 Anthropic 의 정책을 따릅니다. 문의는 이 프로그램을 나눠 준 운영자에게 하세요.
